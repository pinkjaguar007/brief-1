# Élan Fitness — Multipage Website

A website built with **HTML5** and **CSS3**, featuring four pages: Home, About, Programs, and Contact.

## What I Learned and Applied

**HTML:** page structure, semantic elements, headings and paragraphs, links between pages, images and `alt` attributes, forms using `label`, `input`, `textarea`, and `required`, page titles, and SEO meta descriptions.

**CSS:** selectors, classes and IDs, the box model (`box-sizing`), margins and spacing, colors and typography, Flexbox, cards, rounded borders, shadows, `:hover`, `:focus-visible`, and `position: sticky`.

## Files

index.html` — Home
a-propos.html` — About
programmes.html` — Activities and memberships
contacter-nous.html` — Contact details and form
style.css` — Shared styles
img/` — Images and icons
